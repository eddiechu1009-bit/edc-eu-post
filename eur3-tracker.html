7/1 三大新制生效追蹤

2026/7/1 同日生效：€150 免稅廢除 + €3 小包過渡關稅、EU-US 貿易協議、鋼鐵保障新制——跨境賣家到岸成本一次重定錨。

更新時間：2026-07-02 · 資料來源：歐盟執委會稅務海關總署、EEAS、Reuters、Global VAT Compliance、InternetRetailing 等交叉驗證

📌 一分鐘總結

2026/7/1 是歐盟貿易規則的「三制同生效日」：①€150 免稅廢除 + €3 小包過渡關稅（≤€150 非歐盟小包取消免稅，改按每一稅則品項行課 €3，與 VAT 分開，適用至 2028/7/1 海關數據中心上線）；②EU-US 貿易協議歐盟側生效（EU 對美工業品降至零關稅、美對歐多數出口封頂 15%）；③鋼鐵保障新制（免稅配額砍 47%、配額外課 50%）。對跨境賣家而言，真正的衝擊點不是「多繳 €3」，而是 (1) 低單價直郵品的實質稅率被推高（€8 商品約 +40%）(2) 退貨變二次清關、文件不全成本恐遠超 €3 (3) 純跨境直郵小賣家最受壓、有在地倉與 IOSS 的賣家相對有護城河。

🗂️ 7/1 同日生效的三大新制
稅務 · 影響最廣

€150 免稅廢除 + €3 小包關稅

7/1 起非歐盟、價值 ≤€150 小包取消免稅，改按海關申報「每一稅則品項行（HS code line）」課 €3 過渡關稅，與 VAT 分開；混品項包裹按行數疊加（3 種品項 = €9）。適用至 2028/7/1 海關數據中心上線。

貿易 · 不確定性下降

EU-US 貿易協議

歐盟側 7/1 正式生效：EU 對美所有工業品降至零關稅、擴大海產農產准入；美對歐多數出口（含汽車、藥品、半導體）關稅上限鎖 15%。帶保障條款、2029 年底到期，美方違約時 EU 可暫停優惠。

貿易 · 供應鏈外溢

鋼鐵保障新制

年度免稅鋼鐵進口配額砍 47% 至 1830 萬噸、配額外對 26 類鋼品課 50% 關稅；UK 等 13 個 FTA 國配額僅減 1/3。對電商賣家的外溢在含鋼零件、金屬製品、工具、家具五金、家電的到岸成本。

註：€3 為「每稅則品項行」固定費，單價越低佔比越高。混品項包裹按行數疊加（例：3 種不同品項 = €9）。低單價、無在地倉可攤成本的純跨境直郵賣家最受壓。

⚠️ 真正的盲點：退貨變二次清關

顧問圈示警：每一筆跨境退貨都可能成為獨立海關事件

2026-06-30 · InternetRetailing 顧問投書

7/1 起真正的成本不在繳 €3，而在「double-duty 二次清關陷阱」：缺文件、缺可追溯性、缺流程控管的賣家，退貨的合規成本恐遠超新關稅本身。核心風險是進口清關 + 退貨清關的雙重申報、HS code 分類正確性、單據可追溯——處理錯誤可能被課雙重稅或卡關。

「7/1 起，每一筆退貨都可能成為另一個海關事件——€3 反而是最小的挑戰。」—— Shopreturns 顧問, 6/30

11 月還有第二波：處理費 + 強制 PID

2026-11-01 · 歐盟後續時程

11/1 起最遲再加歐盟「處理費」（早期提案約 €2/件）+ 強制 PID 產品識別碼申報，成本與資料義務再升級。7/1 只是第一波，資料合規門檻會分階段拉高。

💡 跨境賣家行動清單

  • 先算實質稅率、再決定通路：低單價品（€8–€15）€3 等於加 20–40% 成本，純直郵已難有利潤——這類品項優先評估轉入歐盟在地倉/IOSS 履約，把 €3 攤薄或閃過。
  • 把退貨清關 SOP 建起來：7/1 起退貨是「二次海關事件」，先確認退貨的 HS code 分類、單據可追溯、退運文件齊全，避免被課雙重稅或卡關——這比省 €3 更關鍵。
  • 混品項包裹重新檢視：€3 按稅則品項行疊加，多品項合寄會讓費用倍增，評估是否調整併單策略。
  • IOSS 與在地履約是護城河：已落實 IOSS 申報、在地倉、品項資料齊全的賣家相對抗壓；長尾純直郵賣家風險最高，宜及早調整。
  • 對美出口的歐洲品牌看 15% 上限：EU-US 協議把美對歐關稅封頂 15%（低於先前威脅），對美出口毛利結構已被墊高但能見度到 2029；留意 Trump 數位稅施壓等變數。
  • 含鋼品類注意到岸成本：金屬製品、工具、家具五金、家電即使非鋼鐵直接進口，也可能透過供應鏈被動吸收鋼鐵配額外 50% 關稅的漲價。
  • 備妥 11 月第二波：PID 產品識別碼與處理費會再拉高資料義務，現在就把產品主檔（HS code、材質、識別碼）整理到位，屆時不必臨時抱佛腳。
